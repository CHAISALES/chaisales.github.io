# Kit de produção · Coruja Criativa Tech

Vídeos verticais 1080x1920 gerados a partir de HTML animado.

- `modelo_reel.html`: série "Leia de novo" (gancho → conversa simulada → o que a família pede de verdade → duas respostas → lição → CTA).
- `modelo_reel_lista.html`: variação com conversa + 3 regras.
- `make.py`: `python3 make.py <nome_sem_extensao> <duracao_em_segundos>` gera `<nome>.mp4` (Playwright + ffmpeg, áudio silencioso).
- `logo.png`: coruja usada no rodapé.

Regras: identidade (fundo #071C24, ciano #38D9F0, Inter), aviso "SIMULAÇÃO BASEADA EM SITUAÇÕES REAIS", nomes fictícios, nenhum cliente real, nenhum vídeo de terceiros. Rodapé: "Coruja Criativa Tech · Atender não é resolver". Fechamento com o bordão "Atender não é resolver. Escola que resolve, matricula."
